# extension-forge
ExtensionForge es un módulo de PowerShell 6 que automatiza la creación, el desarrollo, el empaquetado y el despliegue de extensiones de navegador (Manifest V3) construidas con Angular + Angular Material, compatibles con Google Chrome y Mozilla Firefox.  Un Wizard interactivo te guiará desde desde el scaffolding hasta el despliegue en las tiendas.
