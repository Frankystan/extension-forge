# ExtensionForge - Módulo Principal

Este directorio contiene el módulo PowerShell reutilizable para gestionar el ciclo de vida de extensiones de navegador.

## Estructura
- `Public/`: Comandos expuestos al usuario.
- `Private/`: Funciones y helpers internos.
- `Config/`: Configuraciones por defecto y entornos.
- `Templates/`: Plantillas Angular MV3 y manifiestos.
