# ExtensionForge - Scripts Auxiliares

Contiene scripts de mantenimiento, automatización local, control de versiones y migraciones.

- `Install-ExtensionForge.ps1`
- `Invoke-LocalCI.ps1`
- `Invoke-LocalCD.ps1`
- `Invoke-SemVerRelease.ps1`
- `migrations/`: Scripts históricos y parches (ej. `Repair-*`).
- `archive/`: Versiones anteriores conservadas por compatibilidad.
